# Rust 整体认知与学习路线

> 本目录的目标：让一个对 Rust 一无所知的初学者，按 16 节课循序渐进，建立起对 Rust 的完整心智模型，并能开始读写真实的 Rust 项目。

---

## 一、Rust 是什么

Rust 是一门 **系统级编程语言**，由 Mozilla 在 2010 年推出，目前由 Rust 基金会维护。它的核心目标只有一句话：

> **在不依赖垃圾回收（GC）的前提下，保证内存安全和线程安全，同时拥有和 C/C++ 同级别的运行性能。**

它通过编译期的 **所有权（ownership）+ 借用检查（borrow checker）+ 生命周期（lifetime）** 三件套，把传统语言里那些只能在运行时才暴露的问题（空指针、悬垂指针、数据竞争、内存泄漏、迭代器失效……）大部分搬到了编译期。

---

## 二、Rust 的语言特性（一句话总结）

| 特性 | 含义 | 你将在第几节学 |
|---|---|---|
| 默认不可变 | `let` 声明的变量默认不能改，需要 `mut` | 01 |
| 强类型 + 类型推导 | 类型严格，但局部变量通常可以省略类型 | 02 |
| 表达式语言 | `if` / `loop` / 代码块都能返回值 | 03、04 |
| 所有权系统 | 每个值有唯一所有者，离开作用域自动释放 | 05 |
| 借用与引用 | `&T` 共享借用、`&mut T` 独占借用 | 06 |
| 代数数据类型 | `struct` + `enum` + `match` 描述任意数据 | 07、08 |
| 没有 null | 用 `Option<T>` 替代 null 指针 | 08 |
| 没有异常 | 用 `Result<T, E>` 和 `?` 处理错误 | 11 |
| 零成本抽象 | 泛型 / trait 在编译期单态化，不付出运行时代价 | 12、13 |
| 生命周期 | 让编译器知道引用之间的有效期关系 | 14 |
| 现代异步 | `async`/`await` + Future，无 GC 的协程 | 16 |
| 强大的工具链 | `cargo` 一统构建、测试、文档、发布 | 10 |
| 宏系统 | `println!`、`vec!`、`derive` 等元编程能力 | 15 |

## 三、Rust 擅长哪些领域

Rust **不是万能的**，了解它的擅长领域能帮你判断"什么时候该选 Rust"。

- **系统底层 / 嵌入式**：操作系统、驱动、固件、单片机（替代 C/C++）。
- **高性能服务端**：网络代理（Cloudflare、字节）、数据库（TiKV、SurrealDB）、消息队列。
- **WebAssembly**：编译到 Wasm 后体积小、速度快，是浏览器端高性能计算的主力。
- **CLI 命令行工具**：单文件可执行、跨平台、启动快（`ripgrep`、`fd`、`bat`、`uv` 等）。
- **基础设施工具**：构建工具（`cargo`、`turbopack`）、容器运行时（`youki`）、前端工具链（`swc`、`biome`、`rolldown`）。
- **区块链 / 加密**：Solana、Polkadot、几乎所有现代公链。
- **游戏引擎 / 图形**：Bevy、wgpu。

**不太适合的场景**：
- 快速原型 / 一次性脚本（写起来比 Python、Go 慢）。
- 与 GC 语言生态深度绑定的领域（如安卓 App 主力、富 UI 桌面应用——虽然在追，但还不成熟）。
- 编译期复杂、构建时间长，对"上线快"敏感的业务可能不合适。

## 四、Rust 的设计哲学（理解这几条，能少走很多弯路）

1. **错误尽量在编译期暴露**：宁愿编译慢、报错多，也不愿运行时崩。
2. **显式优于隐式**：可变要写 `mut`、不安全要写 `unsafe`、克隆要写 `.clone()`、错误要写 `?`，**没有隐藏开销**。
3. **没有空值，只有"可能没有"**：用 `Option<T>` 把"也许没值"表达进类型系统。
4. **没有异常，只有"可能失败"**：用 `Result<T, E>` 把"也许出错"表达进类型系统。
5. **数据要么独占要么共享，不能既共享又可变**：这是借用检查器的根本约束，也是无 GC 安全并发的基础。
6. **零成本抽象**：高级语法（泛型、迭代器、async）在编译期被展开成等价的底层代码，不带运行时税。

## 五、学习路线图（16 节课）

每一节都对应 `rust-pices/NN_xxx.rs` 一个可独立运行的小程序。建议**按顺序学**，因为后面的概念严重依赖前面。

| 阶段 | 课程 | 主题 | 核心收获 |
|---|---|---|---|
| **基础语法** | 01 | 变量与可变性 | `let` / `mut` / `const` / shadowing |
| | 02 | 数据类型 | 标量、元组、数组 |
| | 03 | 函数与作用域 | 函数签名、表达式 vs 语句 |
| | 04 | 控制流 | `if` / `loop` / `while` / `for` / 范围 |
| **核心独有** | 05 | 所有权与借用 | move / clone / Copy |
| | 06 | 引用与切片 | `&T` / `&mut T` / `&str` / `&[T]` |
| **类型建模** | 07 | 结构体与方法 | `struct` / `impl` / 关联函数 |
| | 08 | 枚举与模式匹配 | `enum` / `match` / `Option` |
| | 09 | 常用集合 | `Vec` / `String` / `HashMap` |
| **工程化** | 10 | 模块与包 | `mod` / `use` / Cargo 工程结构 |
| | 11 | 错误处理 | `Result` / `?` / `panic!` |
| **抽象与复用** | 12 | 泛型 | `<T>` / 单态化 |
| | 13 | trait 与 trait bound | 接口抽象、默认方法 |
| | 14 | 生命周期 | `'a` 标注、`'static` |
| **进阶** | 15 | 标准库与宏 | 常用宏、Option/Result 组合子 |
| | 16 | 异步与 await | `async`/`await`、Future、运行时 |

学完这 16 节，你应该已经能：
- 看懂大多数开源 Rust 项目的源码。
- 在 Cargo 工程里写出符合 Rust 风格的代码。
- 知道遇到问题该查 `std::option::Option`、`std::collections::HashMap` 这些标准库文档。

## 六、配套工具与生态（最低限度该知道的）

| 工具 | 作用 |
|---|---|
| `rustup` | Rust 工具链管理器（安装、切换版本）。 |
| `cargo` | 构建 / 测试 / 文档 / 发布"一条龙"。 |
| `rustc` | 底层编译器，单文件练习时直接用。 |
| `clippy` | 官方 lint，强烈建议每次提交前 `cargo clippy` 跑一遍。 |
| `rustfmt` | 官方格式化器，`cargo fmt` 自动整理代码。 |
| `crates.io` | 官方包仓库，类似 npm/PyPI。 |
| `docs.rs` | 所有公开 crate 的自动生成文档站点。 |
